## Contract and fail-closed behavior

assess(symbol, rows, now=aware_datetime, session=ISO_date, contract=..., policy=...,
pagination_complete=..., provider_error=..., synthetic=True) accepts exact SPY/QQQ.
All clocks/inputs are supplied; synthetic=True is required, a caller assertion not
authentication. No real-record authority follows from this API.

Rows are Python JSON-like dictionaries: symbol,time (unchanged raw stamp), open/high/
low/close/volume as finite native int/float, and source_sha256.
Contract must explicitly supply sourceSHA256; nonempty source/mapping/calendar/
availability/completion/finality authorities; exchange_timezone; expected interval list.
Each interval binds raw_stamp to aware start/end/available_at, completed=True and
finality=FINAL. Start/end must span60seconds, be in the requested session according to
the supplied exchange timezone, not overlap, and have unique raw/canonical intervals.
The expected grid comes from caller-supplied calendar evidence, never generated by
assuming09:30/16:00, holidays, early closes or DST. Unknown/unavailable calendar/timezone
data blocks. There is NO implicit raw-to-interval shift. Even16:00 is retained only if
explicitly mapped; synthetic tests exercise both blocked and explicit mapping cases.

policy.max_age_seconds must be explicit, positive and finite; no default approved age.
Age uses canonical interval end, not filemtime or fetch time. Source binding mismatch,
stale data, future end/availability, availability before end, unfinished/provisional/
unknown-finality candles, missing expected intervals, duplicate raw stamps, wrong/
unmapped session stamps, invalid OHLCV, incomplete pagination and provider failure all
block before EMA. Duplicates are rejected, never silently deduplicated or averaged.
Other exact symbols are isolated; assess each with its own contract/page/failure status.
No rows/authority/policy means no eligibility; no fallback to an older matching signal.

Authority/hash metadata are explicit TRUSTED CALLER claims, not cryptographic provider
authentication, independent review, or actual historical-availability proof. No such
real provider contract has been verified. The default/real-world state remains blocked.
The120-second value in tests is synthetic only, not adopted production freshness.
Source/SDK/OpenD/entitlement/session/adjustment and actual receipt/custody records must
be established by a future reviewed adapter; an authority string alone cannot prove them.

## Pagination and append-only synthetic evidence

collect_pages injects a request callable; never creates a connection/imports SDK.
Status0 means success in this abstract test contract, not an inferred live adapter.
Explicit page/row budgets, first-page requirement, repeated/invalid token detection,
malformed-page/error/exception handling. Prior raw pages retained on failure; complete=False
must block assessment. Successful pagination proves neither session/candle completeness,
finality nor original availability. No automatic retries, raw timestamp edits or fills.

create_store requires synthetic=True and a NEW explicit absolute directory; refuses
existing path. Marker recognizes only this synthetic schema. record_observation creates
a new exclusive UUID.json per observation/revision; fsyncs that file. Stores record sequence,
caller-supplied UTC record time AND original time string, codeSHA256, observation, full
typed raw evidence/hash and supersedes link. Contract/policy context travels in assessment.
For an assessment, pass its exact per-symbol raw list; mismatched raw hashes are rejected.
Nonfinite raw float bits are preserved reversibly as typed float64 hex, separate from raw
data; no NaN/Infinity JSON literals. Stored evidence hashes are integrity checks, not signatures.

Each operation takes an exclusive cooperative lock, including reads; it does not steal or
delete an existing lock. Current same-symbol revision heads only, no forks/cross-symbol
replacement. Read validates sequence/hash/links, refuses foreign stores, linked files and
corrupt/partial records. Previous observation files remain untouched. No existing CSV,
SQLite store or research data is opened or migrated.

Limits: trusted local ownership/cooperative writers; no general filesystem sandbox,
hostile path-swap/ACL guarantee, cryptographic authorship or hardware power-loss guarantee.
A crash may leave a lock/partial record, which blocks further operations; no automatic
deletion/recovery. Operator inspection and a separately reviewed recovery design required.
Direct file fsync is not a portable directory-durability guarantee. No backups/encryption/
retention/real-record management promised. Caller-supplied record time is NOT first market
availability. Synthetic marker cannot authenticate whether caller data is truly fictional.
